# 本地中文说明书语料

该模块负责为“智药问点”Demo 离线准备中文说明书。采集与后续 RAG 入库相互独立：采集器只输出普通 TXT、独立元数据和药品注册表，不调用 Embedding，也不访问 Milvus。

## 来源清单

[`sources.json`](./sources.json) 当前记录了 26 种常见药品的中文说明书候选详情页，为至少 20 种的目标留出换源余量。候选页按以下顺序选择：

1. 39 药品通；
2. 家庭医生在线；
3. 药源网。

清单中的页面只是候选，不能因为存在于清单中就直接进入语料。页面抓取后仍须通过质量门槛。部分药品已经配置同药名备用详情页，采集器会按优先级逐条尝试；26 个候选药品本身也为最低 20 份的目标提供六份余量。

## 运行

在项目根目录执行：

```bash
python -m scripts.corpus.collect
```

默认使用低速串行请求，每两个药品之间等待 10 秒。需要调整访问频率时，可显式传入间隔：

```bash
python -m scripts.corpus.collect --delay-seconds 10
```

采集器不会使用模型补写缺失字段，也不会自动重试同一页面。HTTP 错误、页面结构变化和质量不达标都会记录在本地采集报告中，并继续尝试该药品的下一候选来源。

## 本地产物

以下目录均已被 `.gitignore` 排除，不会进入公开仓库：

```text
data/
├── raw/
│   └── <drug_id>.priority-<n>.html
└── processed/
    ├── documents/
    │   └── <drug_id>.txt
    ├── metadata/
    │   └── <drug_id>.json
    ├── drugs.json
    └── collection-report.json
```

- `documents/*.txt` 只保存说明书正文章节，不包含来源 URL、抓取时间、批准文号、厂家或其他元数据。
- `metadata/*.json` 保存药品身份、来源、原始页面哈希和可用章节。
- `drugs.json` 是药名识别使用的独立注册表，保存稳定 `drug_id`、通用名、别名、剂型、规格、厂家、批准文号以及本地文件路径。
- `collection-report.json` 记录通过和被拒药品，用来定位需要换源的候选页。

后续 RAG 入库必须以 `drugs.json` 为入口读取正文，不能扫描网页缓存，也不能把来源元数据拼进说明书正文。

## 质量门槛

页面只有同时满足以下条件才会写入 TXT 和注册表：

- 提取出的通用名与清单中的预期药名一致；
- 具备批准文号；
- 具备生产企业；
- `适应症`、`用法用量`、`禁忌`、`注意事项` 四项中至少具备三项；
- 中文正文没有短到足以表明页面错位或解析失败。

缺段、错位或药名不符时，采集器拒绝该页面，不进行推测和补写。最终通过数量少于 20 时命令以非零状态结束，并要求补充候选来源。

## TXT 与元数据边界

正文 TXT 仅包含下列可用章节：成份、性状、适应症、用法用量、不良反应、禁忌、注意事项、特殊人群用药、药物相互作用、药理作用、药代动力学和贮藏。

批准文号、生产企业、规格、来源网站、来源 URL、抓取时间、原始网页路径和网页哈希只保存在 JSON 元数据中，不占后续 400 字符正文切片额度。

本模块只为个人展示 Demo 准备短期本地语料。正式版本应替换为具有明确授权的官方正版说明书来源。
